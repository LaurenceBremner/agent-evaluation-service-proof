Methodology

How the service makes a gate decision

  1. Define expected action, required evidence, review requirement, and severity for each case.
  2. Validate every submitted output with explicit Pydantic models.
  3. Subtract deterministic penalties for action mismatch, missing evidence, missed review, low confidence, cost, and latency.
  4. Map case scores to pass, review, or block.
  5. Promote the run to controlled rollout, human-review gate, or blocked release.
